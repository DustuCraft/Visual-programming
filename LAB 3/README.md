# Lab03Calculator — «Интерактивный калькулятор» (JavaFX)

Готовый проект для лабораторной работы №3 по дисциплине «Визуальное программирование».

## Как запустить

**В IntelliJ IDEA (рекомендуется):**
1. Откройте папку `Lab03Calculator` как Maven-проект (IntelliJ подтянет зависимости JavaFX автоматически).
2. Убедитесь, что установлен JDK 17+.
3. Запустите `CalculatorApplication.main()`.

**Через Maven из консоли:**
```
mvn clean javafx:run
```

## Что реализовано

- Интерфейс полностью описан в FXML (`calculator-view.fxml`), редактируется в Scene Builder.
- Все компоненты имеют осмысленные `fx:id` (txtNumber1, txtNumber2, lblResult, lblOperation, btnAdd, btnSubtract, btnMultiply, btnDivide, btnClear, btnExit и др.).
- **Один общий обработчик** `onOperation(ActionEvent)` назначен сразу семи кнопкам (+, −, ×, ÷, xʸ, %, (A+B)/2) — источник события определяется через `event.getSource()`.
- Проверка пустых полей, `try/catch (NumberFormatException)`, проверка деления/остатка на ноль — все ошибки выводятся через `Alert`.
- Кнопка «Очистить» (`clear()`, `setText()`, `requestFocus()`) и «Выход» (`Platform.exit()`).
- Свойство `disable` — кнопки «Блокировать поля» / «Разблокировать».
- События мыши `onMouseEntered` / `onMouseExited` на текстовых полях и кнопках операций.

### Самостоятельная часть
- Задание 1 — возведение в степень: кнопка `xʸ` → `Math.pow(number1, number2)`.
- Задание 2 — остаток от деления: кнопка `%` → `number1 % number2`, с проверкой на ноль.
- Задание 3 — результат округляется до двух знаков: `String.format("Результат: %.2f", result)`.
- Задание 4 — счётчик операций: `lblCounter` показывает «Выполнено операций: N».

### Индивидуальный вариант №20 — (A + B) / 2
Кнопка `(A+B)/2` в обработчике `onOperation` вычисляет среднее арифметическое двух введённых чисел:
```java
case "(A+B)/2":
    result = (number1 + number2) / 2;
    break;
```
Эта операция не требует дополнительных проверок (деление на 2 всегда корректно), в отличие от, например, извлечения корня или обратного значения.
